분석 가이드

추천 로직, 데이터 출처, 한계를 공개합니다

LottoGoGo는 숫자를 “예측”한다고 단정하지 않고, 과거 공개 데이터를 기반으로 선택 근거를 정리하는 도구입니다. 번호를 무작위로 찍는 대신, 필터와 점수 기준을 통과한 조합을 제시해 판단 과정을 투명하게 제공합니다.

1) 데이터 출처와 갱신

동행복권 회차 데이터를 기준으로 주기적으로 갱신합니다. 최신 회차 데이터가 반영되면 모델 파일을 다시 생성하고, 브라우저에서 즉시 사용할 수 있도록 경량화된 형태로 배포합니다.

2) 조합 생성 방식

기본 점수(Base)와 흐름 보정(Hot/Cold/Carryover), 그리고 다단계 필터(합계·홀짝·고저·구간·AC)를 조합합니다. 이후 다수 후보 중 점수와 다양성을 함께 고려해 최종 추천군을 정렬합니다.

3) 결과 해석 방법

추천지수는 “당첨 확률”이 아니라 현재 설정에서의 상대적 우선순위입니다. 같은 회차에서도 설정(A/B, 5/10게임, GA/XGBoost)에 따라 결과가 달라질 수 있으며, 이는 서로 다른 가정으로 탐색하기 때문입니다.

4) 반드시 알아야 할 한계

복권 추첨은 본질적으로 확률 사건이며, 어떤 도구도 당첨을 보장할 수 없습니다. 이 페이지의 콘텐츠는 교육/실험 목적이며, 실제 구매 금액과 빈도는 개인의 책임 범위에서 신중히 결정해야 합니다.

자주 묻는 질문

서비스 사용 전 확인하면 좋은 핵심 질문

추천 번호가 당첨 가능성을 높여주나요?

당첨을 보장하지 않습니다. 이 도구는 과거 데이터로 선택 근거를 정리하는 보조 수단이며, 무작위성을 제거할 수는 없습니다. 결과를 절대적 예측으로 사용하기보다, 선택 기준을 일관되게 관리하는 참고 정보로 활용하는 것이 적절합니다.

GA/엔진과 XGBoost 모델은 무엇이 다른가요?

GA/엔진은 규칙 기반 점수와 최적화된 가중치 중심이고, XGBoost는 특징 데이터를 학습한 트리 앙상블 모델입니다. 같은 데이터라도 접근 방식이 달라 결과 조합이 달라질 수 있으며, 두 모델을 비교해 보는 것이 유용합니다.

왜 최근 회차 번호가 일부 포함되기도 하나요?

무조건 배제하면 오히려 편향이 생길 수 있어, 최근 연결(Carryover)을 제한적으로 반영합니다. 과다 반영을 막기 위한 상한 조건을 두고 있어 특정 패턴에 과도하게 쏠리지 않도록 설계했습니다.

이 사이트는 어떤 사람에게 적합한가요?

복권 구매를 권장하기 위한 서비스가 아니라, 번호 선택 과정을 데이터 관점에서 기록·비교하고 싶은 사용자에게 적합합니다. 과도한 지출을 유도하지 않으며, 구매 판단은 언제나 사용자 본인의 책임입니다.
