분석 방법론

최종 수정일: 2026년 3월 1일

1. 이 문서의 목적

이 문서는 LottoGoGo가 번호 추천 결과를 어떻게 생성하는지 사용자 관점에서 이해할 수 있도록 작성되었습니다. 핵심 목표는 "정답 번호 예측"이 아니라 "선택 근거의 일관성"입니다. 따라서 각 단계는 확률적 탐색과 조건 필터링 중심으로 설명되며, 당첨 보장을 의미하지 않습니다.

2. 입력 데이터와 전처리

2-1. 입력 범위

추천 로직은 공개된 과거 회차 번호 데이터를 기반으로 동작합니다. 데이터는 최신 회차까지 반영되도록 주기적으로 갱신되며, 추천 시점에는 브라우저에서 바로 계산 가능한 형태로 모델 파일을 로드합니다.

2-2. 전처리 원칙

  • 숫자 범위 검증(1~45)
  • 회차 순서 정렬
  • 중복/결측 방어 처리

3. 점수화와 후보 생성 개요

번호별 점수를 만든 뒤, 확률 분포로 변환하고, 대량 샘플링으로 조합 후보를 생성합니다. 생성된 후보는 품질 필터를 통과해야 하며, 최종 단계에서 점수와 다양성을 동시에 고려해 순위를 결정합니다.

단계 역할
Base Score 번호별 기본 출현 경향을 확률 형태로 계산
Boost 최근 흐름(Hot/Cold/Carryover 등) 관련 보정값 추가
Normalizer 점수를 샘플링 가능한 확률 분포로 변환
Sampling 대량 조합 생성 후 후보군 확보
Filter 품질 기준에 맞지 않는 조합 제거
Ranking + Diversity 상위 점수 조합 중 번호 겹침을 줄여 최종 출력

4. 필터 기준 설명

필터는 "무의미한 조합"을 줄이기 위한 장치입니다. 단일 규칙이 정답을 만든다는 의미는 아니며, 극단적 패턴이나 과도한 편향을 줄이는 목적입니다.

  • 합계 범위 필터: 번호 총합이 지나치게 낮거나 높은 조합을 완화
  • 홀짝/고저 비율 필터: 한쪽으로 과도하게 치우친 조합 제한
  • 구간/끝자리/AC 필터: 특정 구조적 패턴 편중 완화
  • 과거 고중복 필터: 과거 패턴 재현 과잉 방지

5. 모델 모드 차이: GA/엔진 vs XGBoost

UI에서 선택 가능한 두 모드는 같은 데이터 기반이지만 접근 방식이 다릅니다.

모드 특징
GA/엔진 규칙 기반 점수와 최적화된 가중치 조합에 강점
XGBoost 특징 기반 학습 모델로 비선형 패턴 반영에 강점

두 모드는 서로 배타적 우열을 뜻하지 않으며, 같은 회차에서도 결과가 달라질 수 있습니다. 사용자는 모드별 결과를 비교해 자신에게 맞는 탐색 방식을 선택할 수 있습니다.

6. 결과 카드 해석 가이드

  1. 추천지수: 동일 실행 내 상대 점수입니다. 절대 확률 수치가 아닙니다.
  2. 추천 포인트: Hot/Cold/Carryover 등 선택 근거 태그입니다.
  3. 선정 근거: 필터 통과 요약(합계/홀짝/구간/중복 제어 등)입니다.

7. 한계와 해석 주의사항

  • 복권 추첨은 무작위 사건이므로 장기적 확정 우위 전략은 보장되지 않습니다.
  • 과거 데이터 기반 모델은 구조 변화나 우연적 변동성을 완전히 설명하지 못합니다.
  • 추천 결과는 구매 판단의 참고 자료이며, 책임은 사용자 본인에게 있습니다.

8. 문서 업데이트 기준

추천 로직의 핵심 단계가 변경되거나 UI 해석 방식이 달라지면 본 문서를 업데이트합니다. 주요 정책 문서는 운영 정보, 개인정보처리방침과 함께 유지됩니다.

본 방법론 문서는 사용자가 추천 근거를 이해할 수 있도록 작성한 설명 문서입니다. 이 문서는 투자/재무 조언을 제공하지 않으며, 특정 결과를 보장하지 않습니다.
